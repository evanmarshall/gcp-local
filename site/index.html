Most emulators skip auth. That's the bug.

Local emulators without IAM let code pass locally that fails the moment it meets a real service account — missing grants surface as failed deploys, flaky staging environments, and cloud spend you didn't plan for.

gcp-local issues local credentials and evaluates IAM policies on every request. Denials behave like real GCP: the same codes, the same messages, the same conditions — so you catch the gap in CI instead of in production.

Every requestis authenticated and authorized before it touches state — not a demo flag, the real policy engine
RecordedPredefined roles, status codes and response fields captured once from a real GCP sandbox and replayed in CI
LocalStack-styleSingle gateway routing to per-service providers, reusing real backends (PostgreSQL, MySQL, Redis, Google's own emulators)

What you get

Real client libraries

Point google-cloud-python, cloud.google.com/go/storage, Node.js clients, gcloud or rclone at the local endpoint. No shims, no custom SDKs.

Real IAM enforcement

Allow policies with predefined roles recorded from Google Cloud. Conditions evaluated for Storage and Cloud SQL. Deny rules and principal access boundaries enforced locally.

Recorded & replayed

Scenarios are recorded once against a sandbox project and replayed against the emulator in CI — alongside pinned Terraform acceptance tests and client-library tests.

Real backends where they exist

Pub/Sub, Spanner and Bigtable run Google's official emulator code. Cloud SQL runs PostgreSQL, MySQL and Redis for real. Fake-gcs-server handles objects and resumable uploads.

Full workflows

Terraform-provisioned Pub/Sub → Cloud Run → Cloud Storage pipelines run end-to-end locally. Vertex AI supports generate, stream, count tokens and embed (stub or Ollama).

Batteries included

python3 scripts/local_env.py up|env|reset|down|logs. Generated developer identity with explicit grants. Nothing published to a registry, no accounts created.

Quickstart

Docker with Compose and Python 3.11+. That's it — no Google Cloud account.

git clone https://github.com/evanmarshall/gcp-local.git
cd gcp-local
python3 scripts/local_env.py up
python3 scripts/local_env.py env

HTTP on 127.0.0.1:4566, gRPC on 127.0.0.1:4567, project gcp-local-test. See the client setup guide for Go, Python, Node, gcloud and rclone.

# google-cloud-python, with real IAM semantics
credentials, _ = google.auth.load_credentials_from_file(
    ".gcp-local/environment/identity/adc.json",
    scopes=["https://www.googleapis.com/auth/cloud-platform"],
)
client = storage.Client(
    project="gcp-local-test",
    credentials=credentials,
    client_options={"api_endpoint": "http://127.0.0.1:4566"},
)
bucket = client.bucket("my-bucket")
bucket.iam_configuration.uniform_bucket_level_access_enabled = True
client.create_bucket(bucket, location="us-central1")
bucket.blob("hello.txt").upload_from_string("Hello from local GCP.")
